# rglint

Rust GraphQL Linter.

See [PLAN.md](PLAN.md) for the project plan and architecture.

## CI

[![CI](https://github.com/Intellicode/rglint/actions/workflows/ci.yml/badge.svg)](https://github.com/Intellicode/rglint/actions/workflows/ci.yml)

Pull requests must pass formatting, clippy, dependency checks, tests, and
benchmark compilation on Linux, macOS, and Windows. Linux-only coverage,
parity, and documentation checks are required as well.
