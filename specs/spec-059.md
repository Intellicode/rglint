# Spec-059: SARIF reporter

> Plan reference: §3 (`crates/rglint/src/reporter/sarif.rs`), §2 ("SARIF output hand-rolled"), §10

## Goal

Implement the `sarif` reporter: emit a SARIF 2.1.0 JSON document for GitHub
code scanning upload and other SARIF consumers. Hand-rolled (no mature Rust
SARIF crate per PLAN §2).

## Scope

**In scope:**

- `reporter::sarif` — build a `SarifReport` struct matching the SARIF 2.1.0
  schema subset GitHub requires:
  - `$schema`, `version: "2.1.0"`.
  - `runs: [{ tool: { driver: { name: "rglint", version, rules: [...] } },
    results: [...] }]`.
  - `results`: one per `Diagnostic` with `ruleId`, `level` (`error`/`warning`),
    `message.text`, `locations: [{ physicalLocation: { artifactLocation: {
    uri }, region: { startLine, startColumn } } }]`.
  - `rules`: one entry per distinct rule id fired, with `id`, `name`,
    `helpUri` (link to docs generated by spec-068).
- Serialize via `serde_json` with stable key order.
- Validate the output against the SARIF 2.1.0 JSON schema (vendored) in tests.

**Out of scope:**

- GitHub annotations (spec-060 — different format).
- Fix/suggestion富 SARIF `fixes` (add in a later spec if needed; v1 omits).

## Dependencies

- spec-003, spec-011.
- spec-068 (docs URL — soft; can stub `helpUri` and wire later).

## Deliverables

- `crates/rglint/src/reporter/sarif.rs`.
- `crates/rglint/schemas/sarif-schema-2.1.0.json` (vendored).
- Unit test: generate SARIF for a 2-diagnostic fixture, validate against the
  schema with the `jsonschema` crate.

## Interface / API

```rust
pub struct SarifReporter;
impl Reporter for SarifReporter { ... }
// Output: a single SARIF log JSON object.
```

## Behavior

- `level`: `Error → "error"`, `Warn → "warning"`.
- `region.startColumn` is 1-based (SARIF convention — **not** eslint 0-based;
  convert).
- Rule `helpUri`: `https://rglint.dev/rules/<id>` (stub domain; update on
  release).
- One `run` (rglint doesn't track invocations separately in v1).

## Testing

- JSON-schema validation passes (strong correctness gate).
- Snapshot of a representative output.

## Risks / Notes

- SARIF schema is large; vendor only the subset we emit + validate against.
  Full schema is ~4MB; acceptable in `crates/rglint/schemas/`.
