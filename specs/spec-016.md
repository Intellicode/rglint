# Spec-016: no-anonymous-operations

> Plan reference: §5 Phase 1, §3 (`crates/rglint-rules/src/operations/no_anonymous_operations.rs`)

## Goal

Port the `no-anonymous-operations` rule: report any operation definition
without a name. Leaf rule — exercises the full engine pipeline end-to-end with
minimal logic, validating the skeleton.

## Source

`packages/plugin/src/rules/no-anonymous-operations/index.ts`

## Scope

**In scope:**

- Rule struct + `#[derive(Rule)]` registration with id `no-anonymous-operations`,
  category `Operations`.
- `Handler` subscribing to `OPERATION_DEFINITION` nodes.
- Behavior: if `node.name` is `None`, report `Anonymous GraphQL operations are banned. Please give your operation a name` at the operation's span.
- Suggestion: none (rule has `hasSuggestions: false`).
- `requires_schema: false`, `requires_siblings: false`.

**Out of scope:**

- Other operation rules.

## Dependencies

- spec-008, spec-009, spec-011 (engine pipeline).
- spec-014, spec-015 (fixtures + harness).

## Deliverables

- `crates/rglint-rules/src/operations/no_anonymous_operations.rs`.
- `rules-fixtures/no-anonymous-operations/` (generated by spec-015; verify +
  hand-fix any extraction issues).
- `tests/rule_no_anonymous_operations.rs` using `rglint_test_suite!`.

## Interface / API

```rust
#[derive(Rule)]
#[rule(id = "no-anonymous-operations", category = "operations")]
pub struct NoAnonymousOperations;
```

## Behavior

- Fires once per anonymous operation.
- Message is byte-identical to graphql-eslint's.
- Column = start of the operation keyword (`query`/`mutation`/`subscription`).

## Testing

- `rglint_test_suite!("no-anonymous-operations")` — all valid cases produce
  zero diagnostics; all invalid cases match expected (count, message, line,
  column).
- Snapshot (`insta`) of one invalid case's pretty output.

## Risks / Notes

- graphql-eslint applies this only to executable documents (operations), not
  schema — confirm the handler filters out schema-side operation-like nodes
  (none exist, but the selector should be scoped to executable docs).
