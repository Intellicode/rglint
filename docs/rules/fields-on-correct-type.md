# `fields-on-correct-type`

| Property | Value |
| --- | --- |
| Category | `operations` |
| Default severity | `warn` |
| Requires schema | `true` |
| Requires siblings | `false` |

## Description

A GraphQL document is only valid if all selected fields are defined by their parent type.
